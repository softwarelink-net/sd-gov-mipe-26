## 部署与运行说明
### 环境要求
- Node.js >= 18.0.0
- npm >= 9.0.0

### 依赖安装
```bash
npm install
```

### 本地运行脚本
```bash
npm run dev
```
*注：本项目为纯前端演示，无需启动后端服务，直接访问 http://localhost:5173 即可。*
